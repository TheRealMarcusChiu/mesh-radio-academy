## Third-party software included in the built site

The published site bundles client-side code and styles generated by these
build dependencies. Each is MIT-licensed; their license texts ship in the
corresponding package under `node_modules/` after `npm install`.

| Package | Used for | License |
|---|---|---|
| [Astro](https://github.com/withastro/astro) | Static site build and page runtime | MIT |
| [Starlight](https://github.com/withastro/starlight) | Course layout, navigation, search UI | MIT |
| [Pagefind](https://github.com/Pagefind/pagefind) (incl. `@pagefind/default-ui`) | Static, in-browser search index | MIT |
| [Expressive Code](https://github.com/expressive-code/expressive-code) (`astro-expressive-code`) | Code block styling | MIT |

No third-party fonts, images or icons are bundled. The site uses the
reader's system fonts.
