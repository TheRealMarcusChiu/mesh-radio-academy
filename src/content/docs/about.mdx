Mesh Radio Academy is an independent course. It is not affiliated with or
endorsed by the Meshtastic or MeshCore projects.

## Status

The site foundation is in place: navigation, the home page message trace,
and browser-local progress. The thirteen modules in the
[course outline](../curriculum/) are planned and are being researched. No
lesson, lab result or hardware test is claimed yet.

## Privacy

- There are no accounts, analytics, advertising or tracking.
- The site has no server of its own; it is a set of static files.
- It never asks for or reads your location.
- Reading marks are stored in your browser's local storage on this device
  only. Clear them with **Reset progress** on the [outline page](../curriculum/),
  or by clearing this site's data in your browser. Pages on the same site
  host can read the same browser storage, so treat it as convenience, not
  as private storage.

## Licensing

`LICENSE` and `NOTICE.md` in the source repository for third-party software
used to build the site.

## Report a problem

Found an error, an unclear explanation or a broken link?
[Open an issue on GitHub](https://github.com/TheRealMarcusChiu/mesh-radio-academy/issues).
