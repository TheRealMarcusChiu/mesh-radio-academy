The course runs from a first simulated message to a capstone network you
design, break and fix. Modules 03–04 follow Meshtastic and 05–06 follow
MeshCore; the rest cover both systems with the same assumptions so you can
compare them fairly.

<CurriculumOutline />

## Labs

The [lab index](../labs/) lists all four hardware-free labs and their status in this build:

- [Routing playground](../labs/routing-playground/): available. It covers a Meshtastic broadcast diamond and a
  MeshCore known-path failure with recovery.
- [RF sandbox](../labs/rf-sandbox/), [packet inspector](../labs/packet-inspector/) and
  [field planner](../labs/field-planner/): integration pending. Each is built in its own work stream; until it
  joins this site, the lessons work the same ideas by hand.
